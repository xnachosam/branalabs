# Prompt para Claude Design — Branding de Brana Labs

## Contexto

Estoy lanzando **Brana Labs**, una empresa/estudio de soluciones de software (SaaS) con sede en Argentina. Brana Labs funciona como una "casa matriz" tech que desarrolla y opera múltiples productos SaaS verticales, cada uno con su propia identidad de producto, todos alojados bajo branalabs.com/[producto] (ej: branalabs.com/atalaya).

El primer producto, **Atalaya** (ex-Vigente), es un SaaS para brokers y productores asesores de seguros (PAS) independientes en Argentina, con su propia identidad visual ya definida (verde #1A7A5E / #3db897, tipografías Syne + Inter). Brana Labs necesita su **propia identidad, independiente de la de Atalaya** — es la marca corporativa/paraguas, no un producto en sí.

## Qué necesito

Una propuesta de branding completa para **Brana Labs** como marca corporativa de software:

1. **Logo / isotipo** — el nombre "Brana" debe ser protagonista (viene del apellido del fundador, Sambrana). Explorar variantes: solo wordmark, wordmark + isotipo, isotipo solo (para favicon/avatar).
2. **Paleta de colores** — primaria, secundaria, neutros, fondos dark/light. Debe ser distinta a la de Atalaya (verde #1A7A5E) para que ambas marcas convivan sin confundirse, pero que funcionen bien juntas (ej. en un footer "powered by Brana Labs" dentro de la web de Atalaya).
3. **Tipografía** — heading + body, idealmente de Google Fonts (gratuitas, buen soporte de pesos).
4. **Tono y personalidad de marca** — ver más abajo.
5. **Aplicaciones de referencia** — cómo se vería en: landing page corporativa, favicon, header/nav con logo de producto al lado (ej. "Brana Labs | Atalaya"), tarjeta/social preview (OG image).

## Tono y personalidad

**Tech moderno y minimalista.** Referencias de estilo: Linear, Vercel, Stripe, Raycast — mucho espacio en blanco, tipografía sans-serif limpia, paleta acotada (1-2 colores de marca + escala de grises/neutros), formas geométricas simples, sin ilustraciones recargadas ni gradientes excesivos. Debe transmitir: precisión, solidez técnica, y ser lo suficientemente neutra/flexible como para "albergar" productos con identidades propias muy distintas (seguros, y lo que venga después).

## Consideraciones técnicas

- Sitio actual de Atalaya es HTML/CSS/JS vanilla (sin build system) — la propuesta debe ser implementable con CSS puro (variables CSS, Google Fonts vía `<link>`, sin dependencias de frameworks de diseño).
- Debe funcionar bien en dark mode (la estética general de los productos tiende a fondos oscuros).
- Pensar en escalabilidad: la identidad debe poder convivir con futuros productos que aún no existen, sin necesitar un rediseño completo.

## Entregables esperados

- Concepto de logo (descripción + variaciones de uso)
- Paleta de colores con valores hex y su uso (texto, fondo, acentos, estados)
- Sistema tipográfico (familias, pesos, tamaños sugeridos para headings/body)
- 2-3 mockups o descripciones visuales de aplicación (landing corporativa, header con sub-marca de producto, favicon/OG image)
