09 · Tokens

Cómo usarlo

Cargá las fuentes y los dos CSS. Toda la identidad vive en variables.

<!-- fuentes + tokens + componentes -->
<link rel="stylesheet" href="atalaya-tokens.css">
<link rel="stylesheet" href="atalaya-ui.css">

/* usar los tokens */
.cta {
  background: var(--accent);
  color: var(--accent-ink);
  border-radius: var(--r-full);
  padding: var(--s3) var(--s5);
  box-shadow: var(--e-accent);
}
